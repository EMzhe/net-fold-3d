# 图推折纸助手

给考公「图形推理·折纸题」用的小工具：**上传展开图截图 → 自动识别 → 生成可任意角度观察的 3D 立体图**。

在线体验：<https://EMzhe.github.io/net-fold-3d/>

## 功能

- **上传截图**：点击选择 / 拖拽进页面 / 直接 `Ctrl+V` 粘贴
- **自动识别**：正方体（四边形展开图）、正四面体（三角形展开图）都能识别
- **一图多形**：截图里有 A/B/C/D 多个选项并排时，自动逐个识别并给出切换条，点「第 N 个」即可逐个分析
- **抗干扰**：自动剔除题干文字、噪点、虚线、涂色面、面内图案带来的影响
- **真实贴图**：每个面的图案直接取自截图对应区域，圆、叉、三角等符号原样贴到立体图形上
- **任意角度**：四元数轨迹球，**360° 无限制自由翻滚**（没有角度限制、不会万向锁），
  `Shift`+拖拽或 ↺ ↻ 按钮做画面内滚转，滚轮/双指缩放，另有前/后/左/右/上/下视角快捷键
- **按图片原样折叠**：3D 里的展开图与截图完全同向（不做任何镜像），图案朝外折成立体图形
- **折叠动画**：拖动「折叠进度」或点「播放折叠」，看展开图一步步折成立体
- **对面关系**：直接列出三组互相正对的面（带缩略图）——折纸题最常考的结论
- **有效性判定**：不是 11 种有效展开图之一时会提示「折叠后重叠」
- **手动修正**：识别不准可直接在图上点击格子增删，或用「框选裁剪」只截出展开图再识别

## 本地运行

纯静态站点，无需构建：

```bash
# 直接用浏览器打开
双击 index.html

# 或起一个本地服务
python -m http.server 8000
```

图片全部在本机浏览器中处理，不会上传到任何服务器。

## 关于折叠朝向

图像坐标 y 向下、3D 世界 y 向上，两者互为镜像。`js/fold.js` 在把展开图搬进 3D 时
会显式做一次 **Y 镜像**（`M.scaling3(k, -k, k)`），否则展开图在 3D 里是上下颠倒的——
那是一次镜像操作，会改变手性，折出来的立方体各面排布与实际展开图正好相反，图推题的结论会全错。
镜像后顶点绕向也要相应反转，保证各面法线朝 +Z（图案面朝观察者），折叠方向取「背离观察者」，
于是折成的立体图形**图案朝外**。方位标签里 +Y 为「上」。
`test/test.js` 里有 5 条断言专门锁住这个朝向，改动折叠引擎时请勿绕过。

## 使用建议

截图尽量只包含展开图本身、画面干净识别更准。带题干文字、多个选项并排、涂色面、虚线、噪点等情况也已做处理；
若某个面识别漏了，会被自动补上（提示「自动补上 N 个面」），也可以用「框选裁剪」截出干净区域后重新识别。

## 识别流程

1. Otsu 二值化 → 必要时去孤立噪点 → 膨胀闭缝
2. 暗连通域按空间邻近聚类，把一张图里的多个图形（选项、题干文字）分开
3. 对每个候选图形：检测长直线 → 投票格距（含 ±1/±2 细化、外轮廓线估计）
   → 逐格四边完整度打分 → 粗评估（容差 2px）+ 精调（容差 1px）选出最优网格
4. 面数不对 / 折不成正方体时，用「疑似面」自动补/删/替换到能折成正方体
5. 多个候选里取可信度最高的（优先能真正折成立体图形的）
