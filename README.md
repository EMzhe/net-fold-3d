# 图推折纸助手

给考公「图形推理·折纸题」用的小工具：**上传展开图截图 → 自动识别 → 生成可任意角度观察的 3D 立体图**。

在线体验：<https://EMzhe.github.io/net-fold-3d/>

## 功能

- **上传截图**：点击选择 / 拖拽进页面 / 直接 `Ctrl+V` 粘贴
- **自动识别**：正方体（四边形展开图）、正四面体（三角形展开图）都能识别
- **真实贴图**：每个面的图案直接取自截图对应区域，圆、叉、三角等符号原样贴到立体图形上
- **任意角度**：鼠标拖拽旋转、滚轮缩放、自动旋转，另有前/后/左/右/上/下视角快捷键
- **折叠动画**：拖动「折叠进度」或点「播放折叠」，看展开图一步步折成立体
- **对面关系**：直接列出三组互相正对的面（带缩略图）——折纸题最常考的结论
- **有效性判定**：不是 11 种有效展开图之一时会提示「折叠后重叠」
- **手动修正**：识别不准可直接在图上点击格子增删，或用「框选裁剪」只截出展开图再识别

## 本地运行

纯静态站点，无需构建：

```bash
# 直接用浏览器打开
双击 index.html

# 或起一个本地服务
python -m http.server 8000
```

图片全部在本机浏览器中处理，不会上传到任何服务器。

## 目录结构

```
index.html          页面
css/style.css       样式
js/mathx.js         mat4/vec3 数学工具
js/detect.js        截图识别（二值化 / 连通域 / 格点匹配）
js/fold.js          折叠引擎（BFS，绕公共棱旋转，支持动画参数 t）
js/editor.js        截图上的网格编辑与裁剪
js/viewer3d.js      three.js 3D 预览
js/three.min.js     three.js r128
test/test.js        Node 单元测试（node test/test.js）
```

## 使用建议

截图时尽量只包含展开图本身、画面干净识别更准；若题目里有多个选项，用「框选裁剪」框出要分析的那一个再识别。
